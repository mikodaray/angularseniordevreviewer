Components & Templates
▼
Change Detection Strategies

Default checks every component on each cycle. OnPush only checks when input references change, an event fires, or an observable emits via async pipe. Use OnPush for performance in large apps.

@Component({ changeDetection: ChangeDetectionStrategy.OnPush }) class MyComponent { // trigger CD manually when needed: constructor(private cdr: ChangeDetectorRef) {} refresh() { this.cdr.markForCheck(); } }
Lifecycle Hooks (in order)

ngOnChanges → ngOnInit → ngDoCheck → ngAfterContentInit → ngAfterContentChecked → ngAfterViewInit → ngAfterViewChecked → ngOnDestroy. Know which fire once vs every cycle.

Standalone Components (v15+)

No NgModule needed. Set standalone: true, import dependencies directly in imports: []. Preferred for new code.

💉
Dependency Injection
▼
Injector Hierarchy

Angular has a tree of injectors: Root (app-wide singleton) → Module → Component (new instance per component tree branch). providedIn: 'root' registers at root without NgModule.

Injection Tokens
const API_URL = new InjectionToken<string>('apiUrl'); // provide: { provide: API_URL, useValue: 'https://api.example.com' } // inject: constructor(@Inject(API_URL) private url: string) {} // or with inject() function: private url = inject(API_URL);
inject() Function (v14+)

Use inject() in constructors, field initializers, and factory functions. Enables DI outside class constructors, great for composable logic in services and signals.

🔄
RxJS & Observables
▼
Key Operators to Know Cold

switchMap cancels previous, use for search/navigation. mergeMap concurrent, use for parallel requests. concatMap sequential order guaranteed. exhaustMap ignores new while active, use for submit buttons.

Memory Leak Pattern
// ✅ Best: async pipe (auto-unsubscribes) // {{ data$ | async }} // ✅ takeUntilDestroyed (v16+) data$ = this.http.get('/api').pipe( takeUntilDestroyed(this.destroyRef) ); // ✅ Manual unsubscribe in ngOnDestroy private destroy$ = new Subject<void>(); ngOnDestroy() { this.destroy$.next(); this.destroy$.complete(); }
Subject Types

Subject: no initial value, only future values. BehaviorSubject: holds current value, new subscribers get it immediately. ReplaySubject(n): replays last n values. AsyncSubject: emits only last value on complete.

⚡
Signals (v16+)
▼
Core API
import { signal, computed, effect } from '@angular/core'; count = signal(0); doubled = computed(() => this.count() * 2); effect(() => { console.log('count changed:', this.count()); }); // mutate: this.count.set(5); this.count.update(c => c + 1);
vs RxJS

Signals are synchronous and simpler for UI state. RxJS is still better for async streams, HTTP, and time-based logic. Use toSignal() and toObservable() to bridge them.

Functional Guards (v15+)
// Modern — no class needed export const authGuard: CanActivateFn = (route, state) => { const auth = inject(AuthService); return auth.isLoggedIn() || inject(Router).createUrlTree(['/login']); }; // in routes: { path: 'dashboard', canActivate: [authGuard] }
Lazy Loading + Preloading
{ path: 'admin', loadChildren: () => import('./admin/routes') .then(m => m.ADMIN_ROUTES) } // Preload all lazy routes in background: RouterModule.forRoot(routes, { preloadingStrategy: PreloadAllModules })
Route Resolvers

Fetch data before the component activates. Use ResolveFn (functional) to return an observable or promise. Data is available via ActivatedRoute.data.

🗂️
State Management
▼
NgRx Core Flow

Action → Reducer (pure fn, returns new state) → Selector (memoized) → Effect (side effects like HTTP). Use createAction, createReducer, createEffect, createSelector.

Selectors Are Key
const selectFeature = (state: AppState) => state.users; const selectActiveUsers = createSelector( selectFeature, users => users.filter(u => u.active) ); // Memoized — only recomputes when users slice changes
Alternatives

NgRx for large teams, complex state. NGXS for less boilerplate. Akita entity-focused. For smaller apps, a signal-based service with BehaviorSubject is often enough.

Performance Optimization
▼
Key Techniques

OnPush change detection. trackBy in *ngFor to prevent full DOM re-renders. Lazy loading routes and modules. Virtual scrolling with CDK for long lists. Deferred loading with @defer (v17+).

trackBy Pattern
<!-- template --> *ngFor="let item of items; trackBy: trackById" // component trackById(index: number, item: Item) { return item.id; // Angular only re-renders changed items }
@defer (v17+)
@defer (on viewport) { <heavy-chart /> } @placeholder { <skeleton-loader /> }

Key Assertions

🏛️
Architecture Patterns
▼
Smart vs Dumb Components

Smart (container): holds state, injects services, dispatches actions. Dumb (presentational): only @Input/@Output, no service dependencies, fully reusable. Use OnPush on dumb components.

Folder Structure
src/app/ core/ ← singleton services, guards, interceptors shared/ ← reusable components, pipes, directives features/ ← feature modules (lazy-loaded) dashboard/ components/ services/ store/
Micro-Frontend Ready

Use Module Federation (webpack) or Native Federation for splitting Angular apps into independently deployable units. Each MFE has its own routing, state, and deployment.

Auth Interceptor with Token Refresh
Hard
Write a functional HTTP interceptor that: attaches a bearer token to every request, and on a 401 response, calls AuthService.refreshToken(), then retries the original request once with the new token. If refresh fails, logs the user out.
What to cover
  • HttpInterceptorFn signature
  • catchError on the response
  • switchMap into refreshToken() observable
  • Cloning the request with the new token
  • catchError on refresh failure → logout
Your Answer
Reference Answer
export const authInterceptor: HttpInterceptorFn = (req, next) => { const auth = inject(AuthService); const addToken = (r: HttpRequest<unknown>) => r.clone({ setHeaders: { Authorization: `Bearer ${auth.getToken()}` } }); return next(addToken(req)).pipe( catchError(err => { if (err instanceof HttpErrorResponse && err.status === 401) { return auth.refreshToken().pipe( switchMap(() => next(addToken(req))), catchError(refreshErr => { auth.logout(); return throwError(() => refreshErr); }) ); } return throwError(() => err); }) ); };
